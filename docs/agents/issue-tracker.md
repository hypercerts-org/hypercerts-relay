# Issue tracker

The project uses Linear's Hypercerts workspace, Tech team. Retrieve the issue
description and acceptance criteria through the Linear MCP using its TECH identifier.
TECH-587 is the Jetstream parent; TECH-593 through TECH-597 own its implementation.
For review before a commit, pin the starting HEAD and review `git diff <start>`
including newly added files staged for review. Review Standards and Spec separately.
